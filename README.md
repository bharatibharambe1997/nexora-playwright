
# NEXORA Playwright Automation

Enterprise-level Playwright JavaScript automation capstone project.

## Technology Stack

- JavaScript
- Node.js
- Playwright Test
- npm

## Prerequisites

- Node.js
- npm
- VS Code

## Installation

```bash
npm install
npx playwright install
```

## Run Tests

```bash
npm test
```

## Run Headed

```bash
npm run test:headed
```

## View HTML Report

```bash
npm run test:report
```

## Project Structure

- tests: Automated test cases
- pages: Page Objects
- components: Reusable UI components
- fixtures: Test fixtures
- api: API clients and services
- data: Test data
- utils: Helper utilities
- config: Configuration
- auth: Authentication support
- reports: Reporting resources
